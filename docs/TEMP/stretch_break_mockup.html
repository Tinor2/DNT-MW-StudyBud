Simulator

The display is circular — the dashed ring shows the content safe area; anything past it is clipped off-screen. All widgets stay inside. Click any widget for the encoder focus ring (4px accent border, sleep-style). Press = select. The Running screen ticks live and rings the arc (270° sweep, 135°–405° like screen_timer.c).
